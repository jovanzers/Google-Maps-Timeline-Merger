# Google Maps Timeline Merger

Static web app untuk menggabungkan beberapa file Google Maps Timeline JSON.

## Fitur
- 100% client-side: file tidak di-upload ke server.
- Drag & drop atau pilih banyak file JSON.
- Menggabungkan `semanticSegments`.
- Menggabungkan `rawSignals`.
- Menghapus duplikat item yang identik persis.
- Mengurutkan hasil berdasarkan waktu.
- Mempertahankan properti root dari file pertama dan menambahkan properti yang hanya ada di file lain.
- Download otomatis sebagai `Timeline_gabungan.json`.
- Support untuk https://github.com/mahlernim/google-timeline-visualizer
